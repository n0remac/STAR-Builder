# Narrative Builder Stub

## Current behavior

The app focuses on individual STAR responses. It does not generate an overall candidate narrative.

## Future feature

Create a narrative summary that connects repeated themes across positions and saved STAR answers.

## Intended interface

- Summarize strengths, recurring proof points, and gaps.
- Let users choose target themes such as leadership, ownership, ambiguity, or technical depth.
- Optionally attach narrative notes to saved answers.

## Acceptance criteria

- A user can generate a short positioning summary from saved STAR answers.
- The summary cites the STAR answers it uses.
- The narrative can be regenerated after the library changes.

## Known constraints

This should wait until the core STAR library produces enough structured data.
