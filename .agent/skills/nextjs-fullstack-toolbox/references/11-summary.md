# Summary

The philosophy:

```txt
Start simple.
Colocate by default.
Promote only when reuse proves it.

Keep TSX declarative.
Use layouts for repeated page structure.
Use Tailwind for visual composition.
Extract repeated design into primitives.

Keep side effects at the edges.
Put most logic in pure functions.
Use server adapters for server behavior.
Use client adapters for browser behavior.

Use TypeScript for local types.
Use Zod for runtime validation.
Use Protobuf/gRPC for cross-language contracts.

Let the frontend orchestrate views.
Let layouts orchestrate repeated structure.
Let the backend enforce authority.

Grow abstractions only when complexity demands them.
```

The ideal end state is not maximum abstraction.

The ideal end state is:

```txt
The app remains easy to understand at its current size, while having a clear path to grow without rewriting its philosophy.
```
